# مهارت معماری اطلاعات ProPaymun

یک Agent Skill که فقط روی معماری اطلاعات تمرکز دارد و مانند یک متخصص باتجربه، فرد را از بریف اولیه و سؤال‌های تعیین‌کننده تا یک IA حرفه‌ای، شواهدمحور و قابل‌استفاده همراهی می‌کند.

**ProPaymun — پروپیمان** یعنی کامل و پُر؛ اما کامل‌بودن در این پروژه به معنی «آماده تصمیم‌گیری» است، نه تولید سند طولانی و غیرضروری.

[English](README.md)

## چه کاری انجام می‌دهد؟

- حتی اگر کاربر درباره IA چیزی نداند، مرحله‌به‌مرحله او را راهنمایی می‌کند؛
- قبل از تصمیم‌های معماری کامل، سؤال‌های اثرگذار را می‌پرسد؛
- اشیا و محتوا، روابط، سازمان‌دهی، Taxonomy، برچسب‌ها، Navigation، Search، دسترسی، چرخه عمر و Governance را مدل می‌کند؛
- شواهد، مشاهدات، استنباط‌ها، پیشنهادها، تأییدها و مجهولات را با هم مخلوط نمی‌کند؛
- زبان و عمق خروجی را برای محصول، طراحی، تحقیق، محتوا، فنی یا مخاطب عمومی تیم تنظیم می‌کند؛
- تشخیص می‌دهد محیط گفت‌وگومحور است یا ساخت‌محور و متناسب با توانایی واقعی آن عمل می‌کند؛
- وقتی پاسخ تعیین‌کننده‌ای لازم است خودش متوقف می‌شود و به ترفند پرامپت‌نویسی کاربر وابسته نیست؛
- در صورت وجود قابلیت و نیاز واقعی، از جست‌وجوی عمومی وب و منابع متصل استفاده می‌کند؛
- برای طراحی از صفر، بازطراحی، ممیزی یا یک بخش مشخص از IA قابل‌استفاده است.

این مهارت وارد حوزه‌های نقشه‌سازی دیگر نمی‌شود؛ هرکدام از آن‌ها مهارت مستقل خودشان را خواهند داشت.

## تجربه پیش‌فرض

برای ساخت یک IA کامل، مهارت معمولاً:

1. برداشت خود از بریف و شواهد موجود را خلاصه می‌کند؛
2. سؤال‌های کوتاهی را می‌پرسد که پاسخشان معماری را تغییر می‌دهد؛
3. هرجا پاسخ تعیین‌کننده لازم باشد خودش متوقف می‌شود؛
4. برای مجهولات برگشت‌پذیر از فرض شفاف استفاده می‌کند؛
5. بهترین خروجی IA متناسب با محیط فعلی را تحویل می‌دهد.

داشتن بریف مفصل به‌تنهایی باعث تولید فوری IA کامل نمی‌شود، اگر تصمیم‌های مهم نقش، دسترسی، چرخه عمر یا قواعد دامنه هنوز نامشخص باشند. فقط وقتی کاربر صریحاً سرعت یا پیش‌نویس بدون سؤال بخواهد، یک نسخه اولیه و فشرده ساخته می‌شود.

## نصب سریع

```bash
npx skills add https://github.com/kamroncorp/propaymun-information-architecture-skill
```

سپس کافی است طبیعی درخواست کنید:

```text
کمکم کن برای محصولم معماری اطلاعات طراحی کنم. این هم بریف اولیه...
```

کاربر لازم نیست حالت‌های داخلی، Checkpoint، روش توقف یا اصطلاحات IA را بشناسد. کافی است درباره محصولش طبیعی صحبت کند.

### Claude Code

مخزن را در مسیر زیر Clone یا Copy کنید:

```text
~/.claude/skills/propaymun-information-architecture/
```

در محیط‌هایی از Claude که آپلود Skill را پشتیبانی می‌کنند، می‌توان بسته ZIP نسخه منتشرشده را آپلود کرد.

### Codex / ChatGPT

```text
~/.codex/skills/propaymun-information-architecture/
```

### Gemini CLI

```bash
gemini skills install https://github.com/kamroncorp/propaymun-information-architecture-skill
```

### Figma agent و Figma Make

فایل زیر را به‌عنوان Custom Skill آپلود کنید:

```text
adapters/figma-make/propaymun-information-architecture.md
```

سپس `/propaymun-information-architecture` را فراخوانی و محصول را طبیعی توصیف کنید. اگر اطلاعات تعیین‌کننده‌ای کم باشد، مهارت چند سؤال می‌پرسد و در همان نوبت هیچ چیزی نمی‌سازد. وقتی اطلاعات کافی شد، در Figma Make یک کاوشگر تعاملی ساختار IA می‌سازد که نمای اصلی آن سلسله‌مراتب اطلاعات و ارتباطات برچسب‌خورده را حفظ می‌کند؛ نه UI محصول، Sitemap یا User Flow. فعال‌کردن Plan Mode اختیاری است و پیش‌نیاز عملکرد صحیح مهارت نیست.

## خروجی‌ها

محیط‌های گفت‌وگومحور به‌طور پیش‌فرض متن کوتاه و تصمیم‌محور ارائه می‌کنند و فقط پس از پذیرش کاربر سراغ فایل سنگین می‌روند. محیط‌های ساخت‌محور پس از عبور از مرحله توقف هوشمند، کاوشگر ساختاری بومی همان محیط را می‌سازند. تمام فرمت‌ها از یک مدل معنایی واحد IA تولید می‌شوند.

مهارت بر اساس قابلیت واقعی محیط تصمیم می‌گیرد، نه فقط نام مدل یا محصول. متن قابل‌حمل همیشه در دسترس است؛ Markdown یا Mermaid، خروجی تعاملی و دیاگرام حرفه‌ای فقط زمانی انتخاب می‌شوند که محیط آن‌ها را پشتیبانی کند و واقعاً مفید باشند.

دیاگرام IA اختیاری است. ساختار متنی همیشه در دسترس است و در صورت درخواست می‌توان از Mermaid، HTML/SVG یا قابلیت دیاگرام نصب‌شده استفاده کرد.

### ابزارهای مکمل اختیاری دیاگرام

- [Excalidraw Diagram Skill](https://github.com/coleam00/excalidraw-diagram-skill) — برای ورک‌شاپ و توضیح مفهومی

## مدل معنایی قابل‌حمل

اگر کاربر استفاده ساخت‌یافته بخواهد، مهارت می‌تواند مدل JSON مستقل از ابزار رندر تولید کند. در محیط دارای Python:

```bash
python scripts/validate_ia_model.py path/to/ia.json
python scripts/render_ia_html.py path/to/ia.json -o ia.html
```

در محیط فقط‌چت، منبع در همان پاسخ ارائه می‌شود و مهارت ادعا نمی‌کند که اسکریپتی اجرا شده است.

## توسعه و ارزیابی

```bash
python scripts/package_figma.py
python -m unittest discover -s tests -v
python /path/to/skill-creator/scripts/quick_validate.py .
```

فایل [`adapters/manifest.json`](adapters/manifest.json) نسخه مشترک و رفتار تحویل Claude، ChatGPT/Codex، Gemini و Figma Make را ثبت می‌کند. تست‌ها هماهنگی نسخه هسته، آداپتور تولیدشده Figma، مستندات و manifest را کنترل می‌کنند.

سناریوهای رفتاری شامل بریف طبیعی فارسی، توقف خودکار، پاسخ حداقلی کاربر تازه‌کار، محیط فقط‌چت، ساخت در Figma Make، جست‌وجوی عمومی، تأیید پیش از تولید فایل و راهکار RTL برای دیاگرام است.

## سیاست کیفیت

مهارت پژوهش یا آستانه موفقیت عمومی اختراع نمی‌کند، معماری آزمایش‌نشده را معتبر نمی‌نامد، فایل ناخواسته نمی‌سازد و بر اساس فرض مهم پنهان تصمیم معماری نمی‌گیرد.
