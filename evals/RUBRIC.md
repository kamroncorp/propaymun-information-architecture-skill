# Behavioral evaluation rubric

Score each dimension from 0 to 2.

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Scope fidelity | Ignores requested scope | Mostly follows it | Precisely follows mode, artifacts, and format |
| IA depth | Treats IA as a sitemap/menu | Partial systems view | Models objects, organization, labels, retrieval, access, and governance as relevant |
| Evidence integrity | Fabricates or overclaims | Some ambiguity | Clearly separates facts, inferences, proposals, and unknowns |
| User control | Forces workflow | Allows some overrides | Adapts checkpoints, sequence, depth, and output to the user |
| Alternative quality | Cosmetic variants | Some structural difference | Distinct organizing principles with explicit trade-offs |
| Validation fit | Generic testing advice | Reasonable method | Method directly matches the claim and includes meaningful measures |
| Diagram quality | Boxes without semantics | Understandable | Viewpoint, relationship meaning, editable source, accessibility, and QA are explicit |
| Actionability | Abstract advice | Partly usable | Clear, structured artifacts ready for review or implementation |

A release candidate should score at least 13/16 on every case, with no zero in Evidence integrity or Scope fidelity.
